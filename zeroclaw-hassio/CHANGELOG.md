# ZeroClaw Home Assistant Add-on Changelog

## 0.1.0 (2026-02-20)

### Initial Release

- Natural language smart home control via LLM agents
- Home Assistant entity tools: get_state, get_states, call_service, fire_event, get_services, get_history
- Event-listener channel (WebSocket subscription to HA events)
- Optional MQTT state caching via Mosquitto
- Embedded WebUI panel via HA Ingress
- Support for all LLM providers: Ollama, OpenAI, OpenRouter, Anthropic, Gemini, etc.
- Security: domain-based entity access control, HA Supervisor token auth
- Configurable through HA web interface
